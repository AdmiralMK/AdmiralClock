# AdmiralClock

Умные часы на ESP32 + круглый дисплей GC9A01 (240×240).

## Возможности
- Аналоговый циферблат с 4 темами (переключение по кнопке BOOT)
- Погода (OpenWeatherMap), курсы USD/EUR, восход/закат
- Фаза луны, пузырьковый уровень на MPU-6500/9250
- Мониторинг RSS МЧС Башкортостана: баннеры тревог и отмен
- VLW-шрифты с кириллицей

## Сборка
1. Скопируйте `include/secrets.h.example` → `include/secrets.h`
2. Впишите Wi-Fi и API-ключи
3. PlatformIO → Build → Upload
